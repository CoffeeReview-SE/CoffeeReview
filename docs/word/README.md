# Nơi lưu file Word

Quy ước đặt tên: `TenFile_vX.Y_YYYY-MM-DD.docx`, ví dụ `SmartShop_BaoCao_v0.3_2026-11-20.docx`.

- Không ghi đè bản cũ khi đã gửi cho người khác. Lưu bản mới với số phiên bản mới.
- Bản đang nộp cho giảng viên đặt thêm hậu tố `_FINAL`.
- Git không tốt khi so sánh file .docx, nên mọi thay đổi nội dung nên ghi thêm vào `docs/bao-cao/` dạng .md trước, rồi mới đưa vào Word.
- File tạm của Word (`~$*.docx`) đã được bỏ qua trong `.gitignore`.
