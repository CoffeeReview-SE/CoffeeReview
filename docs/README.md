# docs

| Thư mục | Dùng để |
|---|---|
| `word/` | Nơi lưu mọi file .docx (bảng phân công, bản báo cáo) |
| `pdf/` | File PDF: yêu cầu đồ án của giảng viên, báo cáo xuất ra nộp |
| `images/` | Ảnh chụp form, mỗi chức năng một thư mục con (trùng tên file trong `progress/`) |
| `erd/` | Ảnh ERD (bản gốc để chèn báo cáo) |
| `bao-cao/` | Bản nháp từng mục báo cáo dạng .md, mỗi người viết phần mình |
| `ai/` | Ghi chú dùng công cụ AI |
| `KE_HOACH_CHI_TIET.md` | Bản kế hoạch chi tiết |
